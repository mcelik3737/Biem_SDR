## Haritaları geri yükleme

[30 Eylül GitHub Release](https://github.com/mcelik3737/Biem_SDR/releases/tag/backup-2026-09-30) içindeki iki isteğe bağlı ZIP ve `SHA256SUMS.txt` kullanılır. Büyük haritalar Git geçmişine eklenmez.

1. Programı kapatın; ZIP dosyasının SHA-256 değerini `Get-FileHash -Algorithm SHA256` ile kontrol edin. Beklenen değerler [paket listesinde](maps/RELEASE_ASSETS_2026-09-30.json).
2. ZIP'leri proje klasörünün **data** dizinine açın. ZIP içinde `map-packs/<paket-adı>/...` yolları vardır. Mevcut paketin üstüne zorla yazmayın; önce onu ayrı yedekleyin.
3. Programı açıp Harita ekranından yol veya uydu katmanını seçin. Çalışma sırasında internet gerekmez.

Bu hazır paketleri genel `Install-MapPack.ps1` görüntü içe aktarıcısına vermeyin: yeni yol paketi MBTiles vektör biçimindedir, doğrudan yukarıdaki klasör düzeniyle kurulur.
